# Aftermarket Specials branch 
## an extension of manifest examples of [IIIF/3d](https://github.com/IIIF/3d)


The purpose of this branch is to maintain a list of example IIIF 3D manifests which are publicly accessible to viewers / viewer developers but which have not been reviewed by 3D Technical Study Group or IIIF Spec editors.

Consider this a staging area for manifest ideas not ready for a PR into [IIIF/3d](https://github.com/IIIF/3d)
